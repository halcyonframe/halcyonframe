Network & display

Settings are stored in config.txt on the TF card. Photos live in /photos. Press KEY on the frame to wake it and see the status screen; hold KEY for 2 seconds to show this page's address on the frame. BOOT shows the next photo.

Firmware

Use halcyonframe.bin from a release. If the new firmware doesn't start properly, the frame goes back to the current one by itself. Without the web page, copy the file to the card as firmware.bin and restart the frame.
